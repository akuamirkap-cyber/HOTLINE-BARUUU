# Local typefaces

These Latin WOFF2 subsets are hosted locally so the menu and game retain their typography without external font requests. Vite also embeds them in the single-file production build.

Downloaded from the following Fontsource npm packages (all version 5.3.0):

- `@fontsource/anton`: Anton Regular, used for the game wordmark and in-game headings.
- `@fontsource-variable/space-grotesk`: Space Grotesk variable, used for menu typography.
- `@fontsource/ibm-plex-mono`: IBM Plex Mono Regular and Medium, used for mission data and keyboard labels.
- `@fontsource/rajdhani`: Rajdhani Medium, SemiBold and Bold, used by the existing game engine.
